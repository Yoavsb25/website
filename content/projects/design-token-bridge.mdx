plan: Define semantic tokens once, generate CSS variables, enforce usage via lint and Storybook-style primitives.
build: Tailwind v4 `@theme`, shared UI primitives, visual regression for both themes.
deploy: Token package published to the monorepo; theme bugs caught in CI before release.
ai: Agents drafted token maps from design specs; lint and visual regression kept generated CSS honest.
outcome: New screens reused tokens instead of inventing colors; theme bugs dropped sharply.

A small system with a large effect on consistency and delivery speed.
